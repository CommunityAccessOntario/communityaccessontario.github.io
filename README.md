# Community Access Ontario — website draft

Static GitHub Pages site. All content is provisional and should be reviewed before public launch.

## Publishing to GitHub Pages

1. Open the `CommunityAccessOntario/communityaccessontario.github.io` repository.
2. Select **Add file → Upload files** (for an empty repository use **uploading an existing file**).
3. Upload `index.html`, `styles.css`, and `script.js` **at the repository root** (not inside a folder). `README.md` is optional.
4. Select **Commit changes**.
5. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**; save.
6. Wait a few minutes and open https://communityaccessontario.github.io/.

## Editing

- Text and investigation pages: `index.html`.
- Colors, layout, sidebar: `styles.css`.
- Navigation logic: `script.js`.
- All pages use URL hashes, so links can point to `/#governance`, `/#fees`, `/#compensation`, `/#insurance`, `/#vendors`.

## Publication precautions

- Review names, claims, dates and sources before publication.
- No private correspondence or personal data should be uploaded without appropriate authorization.
- Replace provisional evidence registers with verified, dated primary-source links.
- The Coalition membership and contact details are intentionally blank.
